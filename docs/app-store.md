## Version 1.0.0

**Promotional text (170)**

A fast, native way to read and update your Jira Cloud issues on iPhone and iPad: search, versions, mentions and daily priorities in one place.

**Description (4000)**

JPlus is a fast, native app for Jira Cloud. Sign in with your site and an API token and get straight to your work.

• My Issues and Mentions: everything assigned to you, and every comment that @mentions you, newest first.
• Search that forgives typos: plain words find issues by title, description and comments, ranked like a web search. JQL is there when you need it.
• Go to anything: type an issue key, a few words of a title or a version name.
• Issue pages that read well: description, comments as threads, images and attachments inline, parent and child issues with progress, and linked Figma designs.
• Edit as you go: title, description, status, priority, assignee, reporter, team and fix versions. Add comments and reply in threads.
• Versions: each release with its progress, and its issues filtered the way you like.
• Daily Priorities: a team checklist for each day, kept as Confluence pages.
• New Ticket from a screenshot: pick a screenshot from Photos, fill in the fields and create the issue with the image attached.
• Draft with Claude (optional): add your own Claude API key and let Claude propose the summary, description and type from the screenshot. JPlus asks before sending anything to Anthropic.
• Several accounts: keep more than one Jira site signed in and switch between them.
• Text size and font: ten text sizes, and the Inter typeface or the system font.

Your sign-in stays in your Keychain. JPlus has no servers of its own, no analytics and no tracking; it talks only to your Jira site, and to Anthropic only when you use Draft with Claude.

Requires a Jira Cloud site and an Atlassian API token.

JPlus is an independent app, not affiliated with or endorsed by Atlassian. Jira and Confluence are trademarks of Atlassian.

## App Privacy

Data Collection → **No, we do not collect data from this app.**
(The developer receives nothing. Data the user sends to their own Jira site,
or to Anthropic with their own key, isn't "collected" in Apple's sense,
because the developer has no access to it.)

## App Review Information

**Sign-in required:** yes. Provide a demo Jira Cloud site:

- User name: the demo account's email
- Password: an API token for that account (see notes)

**Notes for the reviewer**

JPlus is a client for Jira Cloud. To sign in, enter:
• Site: <demo-site>.atlassian.net
• Email: <demo email>
• API token: <token> (paste into the "API token" field; Jira Cloud uses API tokens instead of passwords)

The demo site has sample projects and issues. Draft with Claude is optional and needs the user's own Anthropic API key; it stays disabled without one, and asks for consent before sending anything to Anthropic.
